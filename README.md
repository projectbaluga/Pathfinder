# ProveIT IT Certification Hub

"Prove your IT skills" — ProveIT is an interactive, light-styled, bento-grid dynamic dashboard application built with React 19, react-router-dom 7, and Vite. It contains study reviewers, directories, progress indicators, and practice exam simulations for 25 distinct IT certifications.

## Features

- **Certification Directory:** Browse domains, prices, and detailed metadata with persistent Favorites filters.
- **Study Reviewer:** Structured guidelines and data-driven timeline trackers.
- **Practice Quiz Engine:** Custom mock exam timers, explanation popups, and comprehensive mistake review screens.
- **Progress Tracking:** Dynamic score summaries, mastery stats, and attempts tracking in localStorage.

## Quick Start

```bash
npm install
npm run dev
npm run build
npm run test
```
